# Trading Strategy Simulator

비트코인 거래 전략 시뮬레이션 및 분석을 위한 웹 기반 도구입니다. 횡보장 전략과 순환매매 전략을 지원하며, 실시간 파라미터 조정과 결과 시각화를 제공합니다.

## 🚀 주요 기능

### 📊 **다중 전략 지원**

- **횡보장 전략 (Mean Reversion)**: 양방향 포지션으로 평균회귀 기반 거래
- **순환매매 전략 (DCA)**: 물타기 방식의 단방향 포지션 거래

### 📈 **실시간 시뮬레이션**

- Web Worker를 활용한 백그라운드 계산
- 실시간 진행률 표시 및 로딩 모달
- 파라미터 변경 시 즉시 결과 업데이트

### 📊 **데이터 시각화**

- 에쿼티 곡선 차트 (Recharts 기반)
- 거래 이벤트 로그 테이블
- 승률, 수익률 등 핵심 지표 대시보드

### 📅 **다양한 데이터 지원**

- 2024년 8월 ~ 2025년 7월 (총 8개월)
- 1분봉 BTCUSDT 데이터
- 변환된 CSV 형식으로 정확한 시계열 표시

## 🛠 기술 스택

### Frontend

- **Next.js 15.5.0** - React 기반 풀스택 프레임워크
- **TypeScript** - 타입 안전성 보장
- **Tailwind CSS** - 모던 UI 디자인
- **Recharts** - 데이터 시각화 라이브러리

### Core Libraries

- **@heroicons/react** - 아이콘 라이브러리
- **papaparse** - CSV 파싱
- **Web Workers** - 백그라운드 계산 처리

## 🎯 전략 상세

### 횡보장 전략 (Mean Reversion)

- **개념**: 양방향 포지션으로 가격 변동에 따른 평균회귀 활용
- **파라미터**:
  - 레버리지 (기본값: 12.0)
  - 레그 마진 (기본값: $1,000)
  - 가격 변동 기준 (기본값: 0.35%)
  - 부분 축소 비율 (기본값: 30%)
  - ATR 팩터 (기본값: 0.4)
  - 프리클로즈 시간 (기본값: 45분)

### 순환매매 전략 (DCA)

- **개념**: 물타기 방식으로 하락 시 추가 매수하여 평균단가 낮춤
- **파라미터**:
  - 레버리지 (기본값: 20)
  - 목표 수익률 (기본값: 5%)
  - 초기 마진 (기본값: $2,000)
  - 추가 마진 (기본값: $800)
  - 유지 증거금률 (기본값: 0.5%)

## 🚀 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

### 3. 브라우저에서 접속

```
http://localhost:3000
```

### 4. 빌드 (프로덕션)

```bash
npm run build
npm start
```

## 📊 사용 방법

### 1. 데이터 파일 선택

- 드롭다운에서 원하는 월 선택 (2024년 8월 ~ 2025년 7월)

### 2. 전략 선택

- **횡보장 전략**: 양방향 포지션, 시나리오 선택 가능
- **순환매매 전략**: 단방향 포지션, 물타기 방식

### 3. 파라미터 조정

- 전략에 따라 다른 파라미터 세트 표시
- 실시간으로 값 변경 가능

### 4. 시뮬레이션 실행

- "시뮬레이션 실행" 버튼 클릭
- 진행률 표시 및 로딩 모달 확인

### 5. 결과 분석

- **대시보드**: 총 수익, 승률, 총 거래 수 등
- **에쿼티 곡선**: 시간별 누적 수익 변화
- **거래 이벤트**: 개별 거래 상세 내역

## 🐛 문제 해결

### 시뮬레이션이 실행되지 않는 경우

1. 데이터 파일이 올바르게 로드되었는지 확인
2. 브라우저 콘솔에서 에러 메시지 확인
3. Web Worker 지원 여부 확인

### 결과가 0으로 표시되는 경우

1. CSV 파일 형식 확인 (변환된 파일 사용)
2. 파라미터 값이 적절한지 확인
3. 시나리오 설정 확인
